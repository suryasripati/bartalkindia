# bartalkindia
Fun &amp; Analysts view of Alcohol / State Excise Tax - 2020-2026
Twelve facts to settle your next round with your friends: state liquor tax and drinking, state by state. By Surya Sripati.

A single self-contained page (data, d3 and fonts inlined).
- Opens in **Fun** mode.
- The **Analyst** switch shows the full version: tables, low/best/high ranges, the excise-vs-full-take chart, budget accuracy, caveats.
- `cards/` holds the 12 share images (1200 x 1500 px), in order.

Sources: RBI State Finances (2021-22 to 2025-26), NIPFP WP 415 (2024), ISWAI via CAG, NFHS-6 state fact sheets, Technical Group population projections 2025.
Tax collected is not litres drunk. Best-estimate liquor tax adds VAT and other layers where sources allow and carries real uncertainty.
